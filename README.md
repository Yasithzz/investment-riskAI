# Investment Risk AI

Investment Risk AI is an AI-powered application designed to analyze investment-related risks and help users make more informed financial decisions.

## Features

- Investment risk analysis
- AI-based risk evaluation
- Financial data analysis
- Risk classification and insights
- User-friendly interface
- Data visualization

## Technologies Used

- Python
- Machine Learning
- Artificial Intelligence
- Pandas
- NumPy
- Scikit-learn
- Streamlit
